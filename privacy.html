Privacy Policy

This policy covers the “Corgi English Podcast” app, a private tool that uploads the channel's own videos to its own YouTube channel. Only the channel owner uses it.

What the app accesses

After the channel owner signs in with Google, the app uses YouTube API Services to upload videos, set thumbnails and add subtitles on the owner's own YouTube channel, and to read the channel's name and ID to check that the right channel is signed in.

What the app stores

The sign-in token is saved in a file on the owner's own computer. The app has no server. It does not collect, sell or share any personal data, and it sends no data to anyone except Google's YouTube API.

This website

This website uses no cookies, no analytics and no forms. It is hosted on GitHub Pages; GitHub may log visits as described in its own privacy statement.

Removing access

Access can be removed at any time on the Google security settings page: myaccount.google.com/permissions. Deleting the token file on the computer removes the stored sign-in.

Third-party terms

The app uses YouTube API Services. By using it, the user agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Contact

Questions: use the contact details on the channel's About page.
